# StudyBot — система тестирования через Telegram

### StudyBot — это образовательная платформа с распределенной архитектурой. Преподаватели управляют контентом через современную веб-панель, а студенты взаимодействуют с системой через Telegram-бот.

---

## 🔍 Основные возможности

### 👨‍🏫 **Для преподавателей (Web-интерфейс)**:

* Гибкий конструктор тестов (CRUD операции)
* Управление группами студентов и доступом
* Мониторинг успеваемости в реальном времени

### 👨‍🎓 **Для студентов (Telegram)**:

* Прохождение тестов в привычном мессенджере
* Мгновенная обратная связь и просмотр результатов
* Личный кабинет с историей достижений

---

## 🏗 Архитектура и стек

Система построена на микросервисном подходе, где **Telegram-бот функционирует как обособленный сервис**, взаимодействуя с Backend через API.

### **Backend (Core API)**:

* **Java 17 + Spring Boot 3.1**
* **Spring Security + JWT**: защита данных и авторизация
* **Hibernate + MySQL**: надежное хранение данных
* **Swagger**: интерактивная документация эндпоинтов

### **Frontend (Admin Panel)**:

* **React + TypeScript + Vite**: быстрый и типизированный UI
* **Mantine UI**: библиотека компонентов для чистого дизайна
* **Axios**: клиент для связи с API

### **Telegram Bot (Interface)**:

* **Python + aiogram 3.x**: современный асинхронный фреймворк

---

## 🚀 Установка и запуск

### **Требования**:

* JDK 17
* MySQL 8+
* Node.js 18+
* Python 3.10+

### **Шаги развертывания**:

1. **Backend**:
```bash
cd backend
./mvnw spring-boot:run

```


2. **Frontend**:
```bash
cd frontend
npm install
npm run dev

```


3. **Telegram Bot**:
```bash
cd bot
pip install -r requirements.txt
python main.py

```
